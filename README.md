## 🚀 Running Locally

Open `index.html` directly in any web browser or run a lightweight local static server:

```bash
# Using npx serve
npx serve -l 8080 .

# Or using Python (if installed)
python -m http.server 8080
```

Visit `http://localhost:8080` in your browser.
